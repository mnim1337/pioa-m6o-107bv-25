## Описание функциональности проекта
В memory.py на данный момент реализованы методы создания записей, показ всех введеных записей, их нахождение по фильтру, обновление информации через фильтр и удаление записей так же через фильтр.
В tui.py реализован интерфейс для удобной работы пользователя.
В __main__.py прописан непосредственный запуск прораммы.
В данной работе почти весь код был переписан с использованием принципов ООП.
В test_memory.py реализованы тесты, то есть автоматическая проверка memory.py, в test_tui.py - tui.py. Покрытие кода, которое проверяется при помощи pytest составило 89%
## Инструкция по запуску проекта
1.Можно открыть папку с кодом, т.е. PIOA-M6O-107BV-25 в vscode и прописать в terminal:
```
python -m src.db
```
2.Можно это сделать, например, в PowerShell(для Linux будет Terminal),открыв папку проекта через cd:
```
cd C:\Users\...\...\pioa-m60-107bv-25
```
И прописав команду:
```
python -m src.db
```
