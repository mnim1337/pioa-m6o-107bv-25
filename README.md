## Описание функциональности проекта
В memory.py на данный момент реализованы методы создания записей, показ всех введеных записей, их нахождение по фильтру, обновление информации через фильтр и удаление записей так же через фильтр.
В tui.py реализован интерфейс для удобной работы пользователя.
В __main__.py прописан непосредственный запуск прораммы.
В данной работе почти весь код был переписан с использованием принципов ООП.
В л/р №4 наша цель была реализовать сохранение базы данных (список студентов) не только в оперативной памяти (RAM), как было в л/р №3, но и на жёсткий диск. Формат файла, в котором у нас хранятся данные, — JSON.
В л/р были реализованы новые классы, чтобы адаптировать программу под новые цели (хранение на жёстком диске): класс Table хранит записи в виде словарей, класс FileDatabase сохраняет таблицы в файлы, абстрактный класс Database может сохранить (и не сохранить, если выбрать реализацию MemoryDatabase (in-memory хранение)) таблицу students в JSON.
Как итог, если мы выберем database, то после завершения программы у нас всё ещё остаётся список из студентов, с которым можно в дальнейшем работать, то есть обновлять записи, удалять их и добавлять новые.
В test_memory.py реализованы тесты, то есть автоматическая проверка memory.py, в test_tui.py - tui.py, а в test_file_database.py - database.py.Покрытие кода тестами, которое проверяется при помощи pytest составило 92%

1.Можно открыть папку с кодом, т.е. PIOA-M6O-107BV-25 в vscode и прописать в terminal:
```

```
2.Можно это сделать, например, в PowerShell(для Linux будет Terminal),открыв папку проекта через cd:
```
cd C:\Users\...\...\pioa-m60-107bv-25
```
И прописав команду:
```

```
